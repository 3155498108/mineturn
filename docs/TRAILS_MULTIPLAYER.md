# 多人 AT 战斗与个人友军

本分支使用 Minecraft Java 1.21.1 / NeoForge 21.1.251 / Java 21。客户端、房主或专服都安装相同的 `mineturn-1.0.0-trails.8.jar`，协议为 `30-trails` / `trails-8`。最新实际验证记录在 [任务表](TASKS.md) 顶部。

## 开始联机

正常单人存档仍可直接圈入未命名的友好生物。专用服务器、开放至局域网的存档及已加入第二名玩家的房间使用多人规则；不需要打开另一个玩法开关。

不同队伍、未组队的玩家默认互为对手。同一个原版队伍的玩家互为友军。按住 R 显示范围，松开 R 将圈内可参战单位拉入同一场 AT 战斗，默认半径 20 格。玩家必须处于生存或冒险模式、未骑乘且未在其他战斗中；之后走近的单位不会自动入场。服务器关闭 PvP 时，圈选不会拉入异队玩家和他们的友军；圈内的野生敌对生物仍可参战。同队玩家仍可共同对抗怪物。

多人模式只限制友军：僵尸、骷髅等敌对怪物不需要命名牌。友好生物必须先由主人在战外实际使用命名牌登记，且主人也位于本次参战范围内。已有自定义名字但未登记的生物，以及主人不在场的生物不会参战。命名牌文字没有特殊格式，可自行取名。

## 登记自己的生物

在铁砧中给命名牌取名，然后右键友好生物。成功后会显示「已加入你的队伍」。归属记录为主人的 UUID，跟随实体保存和重新加载；改玩家名字不会把生物送给别人。同一个主人可以继续使用命名牌改名。其他玩家不能通过改名接管，即使已经组队也不能；已有原版驯服主人的狼、猫、马等，只有原主人可以登记。战中不允许登记或改名。

敌对怪物使用命名牌只产生原版命名效果，不会变成可操控队员。生物的原版饥饿、呼吸、日晒等生存条件仍然存在。

## 与其他玩家组队

按 O → 队伍，选择在线玩家发送邀请；对方在自己的 O → 队伍中点击「接受邀请」。未组队时发送邀请会自动建立个人小队。邀请 60 秒有效，必须经对方接受才加入。可先输入名称创建队伍，也可以离开当前队伍；需要切换队伍时先离队再接受新的邀请。

无需管理员权限的等价命令：

```text
/mtparty create 小队名称
/mtparty invite 玩家名称
/mtparty accept
/mtparty leave
```

队伍复用原版记分板团队，成员关系随世界保存。原版 `/team` 管理的队伍也能识别。组队不会转移生物归属；离队后生物仍属于原主人。战中禁止通过上述界面和命令变更队伍；管理员直接更改原版队伍也不会翻转已经开始的这场战斗阵营，下次入战才重新读取。

## 回合、资源与退场

每名玩家只操控自己和自己登记的生物。友军回合不等于你的操作回合：队友的角色或宠物行动时，你可以观察和抢自己的 S，不能替其移动、攻击、用战技或结束回合。UI 显示操控者，生物名单附主人名字。只有自己的角色行动时才允许 E 背包、换装备或主武器；宠物不能使用道具。

CP、主武器、弹药、耐久、食物与道具始终归个人。自己的宠物行动所得 CP 归其主人；角色和宠物受伤所得 CP 也归对应主人。V 抢 S 使用按键者自己的 CP 和主武器，可以打断对手正在播放的普通动作；S 完成后恢复尚存施法者被暂停的动作。已有 S 演出时不能再叠放第二个 S。

同队的范围治疗、力量、速度和鸡的拉条作用于该场同队单位；伤害只处理该场敌对阵营。三个未组队玩家是三个互为对手的阵营，野生怪物组成另一阵营。所有参战者共享行动顺序，客户端按自己的阵营显示左右名单、状态、血量、动画与伤害跳字。

在自己或自己的宠物回合，按 R 退出会带走自己与自己的生物，恢复即时战斗和原镜头；队友和对手有可继续战斗的单位时仍留在场内。离线、换维度或死亡也会清理对应归属的参战单位，避免留下无人操作的回合。友军不在加载范围、没有合适地形或原版不满足参战条件时不会被远程拉来。

## 验证边界

服务器 GameTest 验证规则与专服加载；真实双客户端验收分别核对网络、UI、相机和操作。最终通过范围与日志只在 [任务表](TASKS.md) 记录。跨互联网高延迟、超大队伍、跨维度复杂同时事件、长期平衡以及第三方模组兼容仍需后续验收，不能由本地双客户端结果推定。
