# AT 全生物技能与动画目录

版本：`1.0.0-trails.6`，Minecraft Java 1.21.1。下面 82 行与运行时 `trails_bestiary.json` 逐项对应，包括指令生成的巨人、幻术师、骷髅马和僵尸马。玩家另用六类武器战技与抢 S 系统。

用户所说的“怨灵”按恼鬼（Vex）实现，同时覆盖幻翼。每种生物均有普攻与战技；动画按原版模型能力复用，不声称原版为每种动物提供了专门的攻击动画。没有独立攻击状态的生物使用挥手、行走、振翅或摆尾，再叠加受限前探与技能光效。

## 规则

- 当前单人手动 AT 模式：非敌对生物作为友军，敌对生物作为敌军；动物在原版已把玩家作为目标时作为敌军。友军由玩家手动指挥，可预览后确认普攻／战技，不能用道具。已参战阵营固定，原版目标记忆变化不让它中途变队。
- 普通敌人每 3 次自身行动优先用战技；有 S 的 Boss 在每 3 次自身行动先蓄力 S，其他偶数自身行动使用战技。距离不足先走接近路线；近战不会凭空跨距离命中。
- 非 S 攻击型战技出手发红光。Boss 提前一回合发金光，锁定危险范围／方向，保持到下一次自身回合；画面装饰特效关闭后，金色模型与危险边界仍保留。普通苦力怕使用红色预警。
- S 预告消耗 1.6 倍恢复距离；下一自身回合蓄势 28 tick（监守者音爆为 34 tick 蓄势＋18 tick 出手＋8 tick 收招，连续播放完整 3 秒原版动画），弹道／接触到达再结算，收招 8 tick，之后 2.2 倍恢复距离。普攻／攻击战技为 1.25 倍，支援战技 1.3 倍。鸡 AT 归零例外，不把刚拉到前面的单位再压回队尾。
- 金色预告不是自动胜负判定：可以离开危险区域、防御或抢 S。抢 S 暂停当前演出；若没有击败施法者，其出手阶段会继续。已死或离场施法者的预告会清掉。
- 普通地面范围技能沿用预览的 3 格高差；凋灵／末影龙的空对地范围投影到目标地面并限制 24 格高差。基础威力经原版护甲、免疫、原版伤害事件与防御结算；力量／虚弱影响普通生物伤害，速度状态影响 AT。监守者音波使用原版 sonicBoom 伤害源，保留穿透护甲和墙的特性，方向仍可侧移躲开。
- 原版投射物仅作分离的客户端渲染代理，不加入世界；命中只由服务器执行一次。不炸地形、不生成召唤物、不改变天气。友军自我治疗半径不超过 0.8 格时只作用自身。
