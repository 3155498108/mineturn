# MineTurn AT Prototype 试玩说明

版本：1.0.0-trails.1。面向 Minecraft Java 1.21.1、NeoForge 21.1.251、Java 21，先做单人玩法。

在当前开发电脑可以直接双击项目根目录的 `launch-client.bat`，从正常主菜单进入单人游戏；开发实例的配置、存档和截图位于 `run` 文件夹。启动脚本使用本机已安装的 Java 21 与已缓存的开发依赖，需要保留项目目录，不能把该脚本单独当成发行版启动器使用。

## 安装

1. 在启动器中建立上述 Minecraft / NeoForge 实例，选择 Java 21。
2. 把 `mineturn-1.0.0-trails.1.jar` 放进该实例的 `mods` 文件夹，再启动游戏。
3. 建议用新建的创造模式存档试玩，准备武器、普通箭、风弹、食物和药水，在附近生成僵尸、猪、羊、狼。

本包包含修改后的完整 MineTurn，不要同时安装上游 MineTurn 的另一个 jar。多人及其他模组兼容尚未验收。

## 操作

| 操作 | 默认按键 / 方法 |
| --- | --- |
| 显示选人圈 | 按住 R |
| 将圈内敌我拉入 AT 战斗 | 松开 R；附近必须有可参战敌人 |
| 退出 AT 战斗 | 我方任意单位回合按 R |
| 设置主武器 | 战外手持武器按 B，之后保留该武器在背包中 |
| 抢 S 大招 | CP 至少 100 时按 V，可在敌方回合发动 |
| 选目标 | 点击敌方列表，可翻页 |
| 普通攻击 | 点击按钮，或 Enter / 空格 |
| 友军战技 | 点击按钮，或 F |
| 切换玩家快捷栏 | 数字 1–9，或点击快捷栏 |
| 食物 / 饮用药水 | 玩家回合按 I 或点道具按钮，再选择道具；Esc 返回 |
| 移动 | 点击方向按钮，每回合有移动预算 |
| 调整战斗镜头 | 右键拖动，滚轮缩放 |

R、B、V 可以在 Minecraft 控制设置中重绑定。进入战斗自动切第三人称，退出恢复原镜头。友军每个单位都由玩家逐个下指令，不能使用道具。

## 建议试玩顺序

先用剑对僵尸开战，体验目标选择、扇形攻击和猪羊的战技；再试斧、弓、弩、重锤。弓弩消耗普通箭，风弹重锤要点击专门的组合按钮，消耗风弹并增加行动硬直。

在实时状态从敌人背后命中，看到眩晕与呼吸提示后及时切入，可触发先制：本场敌人各扣最大生命的 25%（至少保留 0.1 HP），我方全员先行动。默认背袭窗口 6 秒，同一目标有 60 秒触发冷却。

战斗中积攒 CP，设置主武器后体验 V 抢 S。默认 CP 上限 200、发动消耗 100；这些数值以及圈半径、鞋子和鞘翅加速、食物效果可在实例 `config/mineturn-trails.json` 调整，重启游戏生效。

## 当前完成度

16 项新规则测试和 389 项可运行上游回归通过；真实客户端已走通入战、第三人称界面、道具页、抢 S 和退出恢复镜头。两份引用缺失实现的上游测试已明确排除，不计入通过项。

这是可试玩原型：Boss 目前使用通用蓄力与范围大招循环，尚未逐个复刻原版阶段；附魔、特殊箭、复杂地形、长期平衡、大队伍实际帧率仍需继续验收。切入效果为原创红黑白程序图形，后续可继续打磨动画与音效。
