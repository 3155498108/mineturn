# MineTurn AT Prototype 试玩说明

版本：1.0.0-trails.4。面向 Minecraft Java 1.21.1、NeoForge 21.1.251、Java 21，先做单人玩法。

在当前开发电脑可以直接双击项目根目录的 `launch-client.bat`，从正常主菜单进入单人游戏；开发实例的配置、存档和截图位于 `run` 文件夹。启动脚本使用本机已安装的 Java 21 与已缓存的开发依赖，需要保留项目目录，不能把该脚本单独当成发行版启动器使用。

## 安装

1. 在启动器中建立上述 Minecraft / NeoForge 实例，选择 Java 21。
2. 把 `mineturn-1.0.0-trails.4.jar` 放进该实例的 `mods` 文件夹，再启动游戏。
3. 建议新建测试存档，用创造模式准备武器、普通箭、风弹、食物和药水，在附近生成僵尸、猪、羊、狼；切回生存模式再进入战斗。

本包包含修改后的完整 MineTurn，不要同时安装上游 MineTurn 的另一个 jar。多人及其他模组兼容尚未验收。

## 操作

| 操作 | 默认按键 / 方法 |
| --- | --- |
| 显示选人圈 | 按住 R |
| 将圈内敌我拉入 AT 战斗 | 松开 R；附近必须有可参战敌人 |
| 退出 AT 战斗 | 我方任意单位回合按 R |
| 设置主武器 | 战外或玩家回合手持武器按 B；玩家回合切换到其他武器时自动更新 |
| 抢 S 大招 | CP 至少 100 时按 V 预览，再按 V 或 Enter 确认，可在敌方回合发动 |
| 选目标 | 弓、斧及友军单体普攻点选敌方；剑、弩的范围方向由右键旋转镜头选择 |
| 圆形落点 | 预览时滚轮调施放距离，右键转向；蓝圈为施放范围，实心图形为生效范围 |
| 范围配置界面 | 进入存档后按 O，或点击战斗界面右上角“设置”；也可从模组配置入口打开 |
| 普通攻击 | 点击按钮或 Enter / 空格先预览，再按 Enter 或再次点击确认 |
| 武器 / 友军战技 | 点击按钮或 F 先预览，再按 Enter 或再次点击确认；Esc 取消 |
| 切换玩家快捷栏 | 玩家回合数字 1–9、点击快捷栏或滚轮；按 E 打开原版背包整理装备 |
| 食物 / 饮用药水 | 玩家回合按 I 或点道具按钮，再选择道具；Esc 返回 |
| 移动 | 我方回合按 WASD，方向跟随镜头；每回合以行动者起点为圆心，绿色圈内自由往返 |
| 调整战斗镜头 | 按住右键拖动；按住右键时滚轮缩放，松开右键后滚轮切快捷栏 |

R、B、V、O 可以在 Minecraft 控制设置中重绑定。进入战斗自动切第三人称，退出恢复原镜头。友军每个单位都由玩家逐个下指令，不能使用道具。

## 建议试玩顺序

先用剑对僵尸开战，点一次攻击查看镜头前方的实心 90° 扇形，转动镜头再确认；弩显示长 24、宽 3 格的矩形，一支普通箭可命中条带内多个敌人。弓和斧仍点选单体。猪可多回合自愈，羊范围回血，鸡的战技使范围内全部友军 AT 归零、排在同 AT 敌人前面，包括鸡自己。再依次试各武器的 F 战技：剑回旋横扫、斧破势重斩、弓满弦狙击、弩多重齐射、重锤风弹震地、三叉戟贯穿投掷。F 先预览，Enter 或再次 F 确认；弓弩消耗 1 支普通箭，重锤消耗 1 个风弹。动作完成前暂不能移动或换装备。

试旋风人时留出挑高空间：它会远程发风弹，将目标击飞并在落地时结算原版摔伤；低天花板会限制高度。骷髅保持远程射击，每三次自身行动会红光蓄力发动强化战技。动画采用原版姿态，退出会恢复。旧实例自定义的范围会继续保留，可用 O 改成 20；本机开发实例原来的 12 格已备份并更新为 20。

在实时状态从敌人背后命中，看到眩晕与呼吸提示后及时切入，可触发先制：本场敌人各扣最大生命的 25%（至少保留 0.1 HP），我方全员先行动。默认背袭窗口 6 秒，同一目标有 60 秒触发冷却。

战斗中积攒 CP，设置主武器后体验 V 抢 S。默认 CP 上限 200、发动消耗 100；`movementRadius` 是移动圈半径，默认 4 格，圈内走动不累计扣距离。默认入战半径 20 格，上下各 6 格。入战半径、上下范围及移动半径可以在 O 设置界面保存；入战范围立即应用，移动半径下回合应用，其他配置字段保留。鞋子、鞘翅和食物数值仍可编辑实例 `config/mineturn-trails.json` 后重启。

顶部 AT 队列用原版皮肤/生物头像表示，悬停可看名字；左右名单显示原版效果图标、等级，悬停看剩余 AV。重复施加的正面战技或饮用药水可叠加等级（默认最多 10 层，`maxBuffStacks` 可调整），力量与迅捷等不同效果同时保留。入战时两侧队伍头像对撞并显示 VS。

## 当前完成度

当前自动化与客户端验证结果见任务表顶部。两份引用缺失实现的上游测试已明确排除，不计入通过项。

这是可试玩原型：Boss 目前使用通用蓄力与范围大招循环，尚未逐个复刻原版阶段；附魔、特殊箭、复杂地形、长期平衡、大队伍实际帧率仍需继续验收。切入效果为原创红黑白程序图形，后续可继续打磨动画与音效。
