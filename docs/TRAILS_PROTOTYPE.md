# 原地切换 AT 战斗：用户规则与原型验收

日期：2026-10-23。此文覆盖本分支与上游玩法冲突的部分；上游历史分工不是本项目的新需求。

## 开发基线

Minecraft Java 1.21.1、NeoForge 21.1.251、Java 21。以 [Matuvent/mineturn](https://github.com/Matuvent/mineturn) 为基础保留 Git 历史与 LGPL-2.1-only 许可证；当前分支增加手动切换和轨迹式规则，不声称为上游官方版本。无需另装上游 MineTurn，也不能同时装两个相同 mod ID 的 jar。

## 已确认的用户规则

- 单人优先；暂不处理第三方模组兼容。
- 同一个按键切入和退出，仅我方回合可以退出。友军生物回合也属于我方回合。
- 显示范围圈，圈内敌人与友军生物原地进入；切入第三人称，退出恢复原镜头。
- 不设固定参战人数上限。性能和 Minecraft 已加载实体/网络仍有实际边界。
- 保留原版血量基础（玩家 20）、护甲与武器；鞋子、鞘翅及速度药水影响 SPD 与 AT。
- 玩家可使用食物、药水；友军手动控制，仅普通攻击和战技。
- 弓单体远程，剑扇形，斧单体高伤，重锤小范围；重锤+风弹为大范围高伤长硬直。
- 实时战斗背袭造成眩晕并触发呼吸提示；此时切入敌方扣 25% 生命，我方全员先行动。
- 主武器决定大招；单独快捷键可以不受当前回合限制抢 S。
- 切入演出采用红、黑、白及斜切构图的原创程序图形，借鉴所述风格，不复制 P5 素材。

## 本轮默认值（可修改，不是用户已经指定的数值）

按住 R 预览，松开 R 入战；战内按 R 请求退出。V 预览 S，再按 V / Enter 确认抢 S；战外或玩家回合手持武器按 B 设置主武器，R/B/V/O 可重绑定。玩家回合用数字键、点击快捷栏或滚轮切换槽位时，自动将所选武器设为主武器；不消耗 CP、行动或 AT。E 打开原版背包，可整理物品、交换武器与护甲，背包中的实际选中武器也会更新主武器。敌方或友军生物回合不允许改动玩家装备。

半径 12 格、上下各 6 格；不自动拉入后续走近的生物。背袭窗口 6 秒，同一目标背袭触发冷却 60 秒，先制资格切入后消耗，避免反复进出重复扣血。25% 暂按最大 HP 计算，最多扣至 0.1 HP。

近战与玩家发射的箭矢等投射物均可触发背袭；要求命中时玩家位于目标后方。普通入战首轮按速度调度，先制入战则确保我方全员先行动。

CP 战斗间保留，上限 200；普通攻击增加 15、友军技能 10、我方受伤 8；S 技消耗 100。200 CP 发动伤害乘 1.5。抢 S 打断敌方等待而保留其回合，玩家下一次行动增加硬直；玩家当前回合发动则结束本回合。

普通动作后恢复距离约 10000；SPD 100 时对应 100 AV。加速保留既有剩余行动距离，改变抵达下一行动的时间；选择指令时 AV 不随现实时间推进，没有 30 秒自动行动。移动改为 WASD 连续控制当前我方行动者，方向跟随镜头；右键拖动旋转镜头。每回合以起点为固定圆心，水平欧氏距离不超过 `movementRadius`（默认 4 格，可在配置中设置 0–32），圈内来回和绕路不累计扣距离，也不推进 AT。服务器每 tick 限速，检查完整碰撞、地面支撑与每段路径的圈边界；不穿墙。下一回合重新取圆心，速度 buff 不会在当前回合重置圆心。中间的方向按钮已移除。

| 武器 | 当前行为 | 恢复距离倍率 |
| --- | --- | --- |
| 剑 | 以镜头朝向为轴，实心 90 度扇形、半径 3 格；不锁单体 | 1.0 |
| 斧 | 单体，装备攻击力 ×1.15 | 1.2 |
| 弓 | 点选单体、24 格，消耗 1 支普通箭，基础伤害 8 | 1.1 |
| 弩 | 镜头朝向的长 24、宽 3 格矩形，消耗 1 支普通箭，基础伤害 10，可贯穿多个敌人 | 1.3 |
| 重锤 | 施放距离 3 格、落点半径 2 格；预览时滚轮调整落点距离 | 1.3 |
| 风弹重锤 | 消耗 1 风弹，半径 5 格、伤害 ×2.3 | 2.2 |

普通物理伤害仍进入原版受伤流程计算护甲；范围效果只处理本场敌方，检查遮挡。附魔和特殊箭并未承诺完整复刻，需在实际游玩后逐项验收。

敌方每三次自身行动使用强化技能；僵尸吸血、骷髅/掠夺者连射、蜘蛛毒击、女巫恢复与毒。Boss 使用通用蓄力—范围大招循环，暂未逐个复刻末影龙、凋灵、监守者的完整原版阶段机制。

食物保留原版食用和饱食度、容器、原有效果，再附加配置回血；药水保留原版饮用和 buff。鞋子加速、鞘翅加速、食物回血、CP 和圈范围读取 `config/mineturn-trails.json`，服务端启动加载；未填写的食物按营养值 ×0.5 回血。

`foodHunger` 和 `foodSaturation` 可按食物 ID 覆盖饱食度、饱和度的增加量；留空时沿用原版。道具页只展示食物与饮用药水，可点击按钮或按 I 打开，Esc 返回；友军回合不开放道具。

## 验证命令与边界

导入的上游 main 中有两份未完成的测试文件，引用仓库中不存在的 `ZombieConversionAccess`、`PiglinConversionAccess`、`BattleMountActions`。本分支保留这两份文件，在 Gradle 精确排除 `ConversionEligibilityRegressionGameTests.java` 和 `MountEligibilityRegressionGameTests.java`，不把它们计为通过，也不为无关骑乘/转化功能编造空实现。

用 JDK 21 运行 Gradle，首次需下载依赖。网络需要代理时仅给本次 Gradle 调用传入 Java HTTP/HTTPS 代理参数，不改用户全局网络设置。

```powershell
.\gradlew.bat build runGameTestServer -PtestNamespaces=trails --console=plain
.\gradlew.bat runGameTestServer -PtestNamespaces=mineturn -PlegacyTests --console=plain
python tools/validate_examples.py
python tools/workspace_context.py --check
.\gradlew.bat runClient --console=plain
```

新机制 GameTest 命名空间 `trails`，使用上游空模板的 `trails:empty` 副本。上游历史集成测试依赖“受伤自动开战”，与本用户的手动入战不同；`-PlegacyTests` 仅在测试进程重新开启该旧入口，以回归底层隔离/状态/物品能力。正常客户端不会启用。

客户端需检查：键位重绑定、圈显示与松开入战、第三人称及退出还原、WASD/松键/视角方向与圆形边界、E 背包与回合内换主武器、各 GUI 缩放、分页与 40+ 友军、目标选择、呼吸灯和切入效果、敌方回合抢 S。服务端测试不能代替这些实机验收。日志与实际结果写入 TASKS.md，未实际执行不得标通过。

## 2026-10-23 交互修订

用户试玩后将累计路程改为回合起点圆形范围。移动输入独立携带战斗 ID、回合编号和递增序号，拒绝旧回合、乱序、非有限方向；服务器按 tick 移动，松键发零输入，丢失心跳五 tick 后停止，切屏和回合结束清空方向。保留原有碰撞、接触与落地处理。

滚轮默认切快捷栏，右键按住时滚轮才缩放。玩家回合按 E 使用原版背包；`ServerPacketMixin` 仅对当前玩家回合且为自身背包的原版包放行，旧模式与非玩家回合继续锁定。换槽/背包交换后重新同步装备属性和主武器大招。

开发验证可用 `-PencounterSmoke -PqaRunDir=build/qa-movement-client -PqaWorld=AT-QA-...` 在独立目录运行，不改常用 `run` 的配置和存档。

## 2026-10-23 范围、状态与演出修订（1.0.0-trails.3）

`TrailsArea` 是客户端预览和服务器结算共用的形状定义。剑用镜头朝向的扇形；弩用镜头朝向的长方形。单体指令仍验证选择的敌人；范围指令无需有效敌人 ID，按脚下位置、水平形状、高差三格及视线过滤，绝不命中友军。范围落空也会消耗正常行动/弹药。图形采用半透明实心填充及边框，显式使用世界渲染事件的矩阵；不能把顶点生成成功当作图形已经显示。

攻击、战技、风弹组合及 S 按钮首先进入预览，不扣费；Enter、再次点击同一动作按钮（S 也可再次 V）才发出执行请求。Esc、切装备或离开界面取消。预览会显示施放距离和生效范围；圆形远程落点可以用滚轮调距离，右键调方向。预览不暂停敌方时钟，回合改变后会取消旧预览。S 仍可在敌方回合确认并抢占。

`Timeline.readyFirst` 让鸡的圈内友军全部行动距离归零，并排在同为零的敌人前，不改场外友军/敌方进度，不推进 AV。当前没有另加鸡战技冷却，包含自身拉条的平衡留待试玩。

原版力量、迅捷、抗性等正面状态重复施加时叠加等级，默认 `maxBuffStacks=10`；持续时间取已有与新效果的较长者。饮用药水保留瓶子与原有效果，先记录已有状态再叠层，避免重复计算。不同状态并存。快照携带效果 ID、等级及持续 tick，GUI 用原版图标与层数显示，悬停换算为 AV，不按现实等待时间倒计时。

O / 战斗右上角设置 / 模组配置入口可打开范围界面，编辑入战半径、上下范围、移动半径。保存由存档主人/管理员验证，范围受限；只改三个字段，保留未知字段，临时文件写完后替换正式配置。入战半径立即生效，移动半径在下回合重新快照。其他配置仍按原启动加载规则。

AT 顶部显示真实玩家皮肤和生物头部原版纹理，名字只在悬停显示；名单补充头像、HP 与状态。入战使用左右队伍头像滑入对撞和 VS，超过六个单位以总数表示，实际参战名单仍无固定人数上限。

移动诊断基线：真实客户端同一段行走的 47 帧中 32 帧镜头不变，最大单帧跳动约 0.305 格（`build-target-baseline.log`）。镜头改为渲染帧插值后，相同 47 帧采样静止帧为 0、最大位移约 0.073 格（`build-target-client-v1.log`）；另外取消 AT 连续移动快照对旧位置与步行动画的周期强制重置。最终流程与测试证据以任务表为准，不把这一小段采样当作所有硬件/网络性能保证。
