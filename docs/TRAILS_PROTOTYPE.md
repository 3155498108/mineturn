# 原地切换 AT 战斗：用户规则与原型验收

日期：2026-10-23。此文覆盖本分支与上游玩法冲突的部分；上游历史分工不是本项目的新需求。

## 开发基线

Minecraft Java 1.21.1、NeoForge 21.1.251、Java 21。以 [Matuvent/mineturn](https://github.com/Matuvent/mineturn) 为基础保留 Git 历史与 LGPL-2.1-only 许可证；当前分支增加手动切换和轨迹式规则，不声称为上游官方版本。无需另装上游 MineTurn，也不能同时装两个相同 mod ID 的 jar。

## 已确认的用户规则

- 单人优先；暂不处理第三方模组兼容。
- 同一个按键切入和退出，仅我方回合可以退出。友军生物回合也属于我方回合。
- 显示范围圈，圈内敌人与友军生物原地进入；切入第三人称，退出恢复原镜头。
- 不设固定参战人数上限。性能和 Minecraft 已加载实体/网络仍有实际边界。
- 保留原版血量基础（玩家 20）、护甲与武器；鞋子、鞘翅及速度药水影响 SPD 与 AT。
- 玩家可使用食物、药水；友军手动控制，仅普通攻击和战技。
- 弓单体远程，剑扇形，斧单体高伤，重锤小范围；重锤+风弹为大范围高伤长硬直。
- 实时战斗背袭造成眩晕并触发呼吸提示；此时切入敌方扣 25% 生命，我方全员先行动。
- 主武器决定大招；单独快捷键可以不受当前回合限制抢 S。
- 切入演出采用红、黑、白及斜切构图的原创程序图形，借鉴所述风格，不复制 P5 素材。

## 本轮默认值（可修改，不是用户已经指定的数值）

按住 R 预览，松开 R 入战；战内按 R 请求退出。V 抢 S；战外手持武器按 B 设置主武器，所有键可重绑定。

半径 12 格、上下各 6 格；不自动拉入后续走近的生物。背袭窗口 6 秒，同一目标背袭触发冷却 60 秒，先制资格切入后消耗，避免反复进出重复扣血。25% 暂按最大 HP 计算，最多扣至 0.1 HP。

近战与玩家发射的箭矢等投射物均可触发背袭；要求命中时玩家位于目标后方。普通入战首轮按速度调度，先制入战则确保我方全员先行动。

CP 战斗间保留，上限 200；普通攻击增加 15、友军技能 10、我方受伤 8；S 技消耗 100。200 CP 发动伤害乘 1.5。抢 S 打断敌方等待而保留其回合，玩家下一次行动增加硬直；玩家当前回合发动则结束本回合。

普通动作后恢复距离约 10000；SPD 100 时对应 100 AV。加速保留既有剩余行动距离，改变抵达下一行动的时间；选择指令时 AV 不随现实时间推进，没有 30 秒自动行动。移动预算每回合约 4 格，原型用镜头相对方向按钮逐步移动，仍检查方块碰撞。

| 武器 | 当前行为 | 恢复距离倍率 |
| --- | --- | --- |
| 剑 | 以选中目标方向为轴，90 度扇形、约 3 格 | 1.0 |
| 斧 | 单体，装备攻击力 ×1.15 | 1.2 |
| 弓/弩 | 24 格、消耗 1 支普通箭，基础伤害 8/10 | 1.1/1.3 |
| 重锤 | 目标周围半径 2 格 | 1.3 |
| 风弹重锤 | 消耗 1 风弹，半径 5 格、伤害 ×2.3 | 2.2 |

普通物理伤害仍进入原版受伤流程计算护甲；范围效果只处理本场敌方，检查遮挡。附魔和特殊箭并未承诺完整复刻，需在实际游玩后逐项验收。

| 友军 | 战技 |
| --- | --- |
| 猪 | 立即恢复 2 HP，后续三个自身回合各恢复 2 |
| 羊 | 周围 6 格友军立即恢复 4 HP |
| 狼 | 周围友军力量 |
| 牛/哞菇 | 周围友军抗性 |
| 鸡/鹦鹉 | 周围友军加速 |
| 猫/豹猫 | 自身防御强化 |
| 铁傀儡 | 范围重拳 |
| 其他友好生物 | 生命鼓舞，后续可逐种改写 |

敌方每三次自身行动使用强化技能；僵尸吸血、骷髅/掠夺者连射、蜘蛛毒击、女巫恢复与毒。Boss 使用通用蓄力—范围大招循环，暂未逐个复刻末影龙、凋灵、监守者的完整原版阶段机制。

食物保留原版食用和饱食度、容器、原有效果，再附加配置回血；药水保留原版饮用和 buff。鞋子加速、鞘翅加速、食物回血、CP 和圈范围读取 `config/mineturn-trails.json`，服务端启动加载；未填写的食物按营养值 ×0.5 回血。

`foodHunger` 和 `foodSaturation` 可按食物 ID 覆盖饱食度、饱和度的增加量；留空时沿用原版。道具页只展示食物与饮用药水，可点击按钮或按 I 打开，Esc 返回；友军回合不开放道具。

## 验证命令与边界

导入的上游 main 中有两份未完成的测试文件，引用仓库中不存在的 `ZombieConversionAccess`、`PiglinConversionAccess`、`BattleMountActions`。本分支保留这两份文件，在 Gradle 精确排除 `ConversionEligibilityRegressionGameTests.java` 和 `MountEligibilityRegressionGameTests.java`，不把它们计为通过，也不为无关骑乘/转化功能编造空实现。

用 JDK 21 运行 Gradle，首次需下载依赖。网络需要代理时仅给本次 Gradle 调用传入 Java HTTP/HTTPS 代理参数，不改用户全局网络设置。

```powershell
.\gradlew.bat build runGameTestServer -PtestNamespaces=trails --console=plain
.\gradlew.bat runGameTestServer -PtestNamespaces=mineturn -PlegacyTests --console=plain
python tools/validate_examples.py
python tools/workspace_context.py --check
.\gradlew.bat runClient --console=plain
```

新机制 GameTest 命名空间 `trails`，使用上游空模板的 `trails:empty` 副本。上游历史集成测试依赖“受伤自动开战”，与本用户的手动入战不同；`-PlegacyTests` 仅在测试进程重新开启该旧入口，以回归底层隔离/状态/物品能力。正常客户端不会启用。

客户端需检查：键位重绑定、圈显示与松开入战、第三人称及退出还原、各 GUI 缩放、分页与 40+ 友军、目标选择、呼吸灯和切入效果、敌方回合抢 S。服务端测试不能代替这些实机验收。日志与实际结果写入 TASKS.md，未实际执行不得标通过。
