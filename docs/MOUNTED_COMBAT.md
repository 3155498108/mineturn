# 骑乘战斗：单人受控坐骑

本组实现**单人可控制生物坐骑**的陆地与水中战斗，包含**战斗中主动上下马**。
坐骑是**移动载体**，不是额外行动者：不注册战斗 AI、不加入行动队列、不获得额外行动或自己的回合。

> 本文以当前源码为准。历史上本页曾写"只有单人陆地载体、没有主动下马行动"，两者都已不成立，见文末「修订记录」。

## 两种进入方式（**不要混为一谈**）

| 方式 | 触发 | 资格判定 |
| --- | --- | --- |
| **入战已有坐骑** | 骑手攻击、或受到实际非致死伤害时已经骑着 | 原版 `getControllingPassenger()`，或已在 `BattleRiding` 注册表中 |
| **战斗中主动上马** | 条件授予按钮（见下） | 上马那一刻重查装备与控制物品 |

**关键差异**：主动上马**只需在上马那一刻**满足控制物品条件；
一旦成功，骑手**切换掉控制物品也不会失去载体**（`BattleRiding.vehicle` 回退查 `RIDERS` 注册表）。
入战已有坐骑则沿用入战时的关系。

## 主动上马与下马

两者都是**条件授予行动**，不是物品映射动作：

| 授予 | 条件 | 默认行动成本 | 默认射程 |
| --- | --- | --- | --- |
| `mineturn:mount`（上马） | `mineturn:nearby_mount`：附近有合格的**空闲**单人坐骑 | `main 0 / bonus 1`（次要行动） | 1.5 |
| `mineturn:dismount`（下马） | `mineturn:riding_mount`：当前正骑着受控坐骑 | `main 0 / bonus 1` | — |

- **成本可配置**：改 `actions/mount.json` 的 `parameters.action_cost`。
- **不补充移动距离**：上马不刷新本回合移动额度；下马也不重置。已消耗的移动照旧。
- **周身约束**：处于敌人周身控制且未撤退时，上下马都会被拒绝（先撤退）。
- **自动安全下马**：下马落点在坐骑周围**曼哈顿 ≤ 2 格、纵向 −1..1** 内择优，要求：
  完整碰撞箱无遮挡、有支撑或为水中落点、起终点之间有清晰扫掠、且视线可达。
  找不到落点即拒绝，不消耗行动。
- **落点重检**：原版骑乘回调之后**再次**校验落点与占位；回调期间地形或参战者变化会导致该次失败。

### 资格条件（`BattleMountActions.equipped`）

| 坐骑 | 条件 |
| --- | --- |
| 马 / 驴 / 骡 / 羊驼等 `AbstractHorse` | 已驯服、已装备鞍、**非幼体** |
| 猪 | 已装备鞍、**非幼体**、骑手手持**胡萝卜钓竿** |
| 炽足兽 | 已装备鞍、**非幼体**、骑手手持**诡异菌钓竿** |
| 骆驼 | **明确排除**（`equipped` 直接返回 false） |

候选还要求：存活、无乘客也无载具、未被战斗锁定、在战场范围内、有视线、包围盒间距 ≤ 射程。
多个候选时取**最近**，距离相同按实体 ID 升序，保证确定性。

> 炽足兽的岩浆行走**不是**"玩家可以下到岩浆"：下马落点仍不接受岩浆等危险流体。

### 事件取消与幂等

`startRiding` / `stopRiding` 返回失败（例如事件取消）时**该次不消耗行动**。
回调期间若战斗归属、行动者、预算或世界发生变化，抛出异常并中止，不留下半完成的骑乘状态。

## 骑手与坐骑的结算

- **队列与目标只含骑手**。点击坐骑外形或提交坐骑实体 ID 都解析为骑手；攻击范围、视线、伤害检查骑手。
- **范围技能对骑乘组合只结算一次**（命中骑手），不对载体重复计一份。这不表示坐骑免伤：
  原版摔伤、燃烧、中毒、呼吸等环境/状态伤害仍可伤害坐骑。
- 坐骑 AI 与原版实时移动被冻结；坐骑状态随**骑手的 AV 状态时钟**推进。
- 退出时解除服务端与客户端状态锁，恢复剩余原版状态。

## 移动与摔伤

- 骑手每回合移动预算 `clamp(4 × 坐骑 MOVEMENT_SPEED / 0.1, 0, 20)`，取坐骑**当前属性值及其修饰**；
  不覆盖骑手敏捷、行动次序或行动次数。疾跑仍翻倍剩余预算。
- GUI 点选的是**坐骑落脚点**；服务端把路线换算成骑手座位坐标，两者同步移动，按实际路线曼哈顿距离扣费。
- 支撑面按坐骑脚下判断；通行空间检查坐骑与骑手的**整体包围盒**（窄门受坐骑宽度限制，骑手头顶也受限）。
- 复用地面有界绕障、上一整格台阶、进入周身范围后停止及撤退规则。预览不移动真实实体。
- 落地与摔伤交给坐骑原版 `fallOn/causeFallDamage`；马的安全摔落距离与向乘客传递由原版处理，
  **不重复结算一份玩家摔伤**。

## 传送与上下坐骑的交互

通用传送接口支持**已纳入骑乘系统的单人受控坐骑整体传送**：传入参战骑手，坐标仍是**骑手脚底**，
内部按座位偏移移动坐骑，不把坐骑额外加入时间轴。规则见 [战斗传送扩展接口](TELEPORT_API.md)。
不支持的骑乘关系、多人/嵌套骑乘会被拒绝。

## 退出与清理

下马、坐骑死亡/移除、关系失效时：中止未完成路线、释放坐骑锁，并把剩余移动距离限制在步行预算内，
**不返还**已消耗的行动或移动费用。骑手继续原战斗。

骑手退战/死亡/离线/数据包重载时释放载体；**不额外把活着的骑手强制下马**。
