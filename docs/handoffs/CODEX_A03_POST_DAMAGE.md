# A03：命中后离场与原版耐久（2026-10-11）

普通玩家/生物近战在伤害与附魔、武器后置回调之间重新检查战斗归属。事件导致攻击者或目标离场后，不继续耐久、横扫、后置附魔或清零目标速度。已发生的伤害与支付的行动不回滚。

新增 `BattleAccess.canFinishAttack`，区分仍在本场的死亡目标与已经离场的目标：正常致死攻击仍支付原版武器耐久。无 BattleAccess 的既有生物近战调用保持兼容。

回归覆盖伤害事件中攻击者/目标离场、已扣行动不返还、授权恢复、正常致死攻击耐久。原版伤害方法在 Post 事件后仍可能施加速度，测试验证模组不抹除离场后的速度，不承诺回滚原版调用内部的副作用。

同期修复 TerrainPath 大世界坐标下的浮点转角重复采样：使用几何容差去重，避免重复点遮住后续下落采样、误判失去支撑而停止。炽足兽上下熔岩岸线测试增加重复采样断言。
