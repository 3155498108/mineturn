# A07 第二批：普通坐骑水域移动

2026-10-11。

有效坐骑使用自身脚底判断是否浸水，骑手坐标继续作为战斗成员位置。AquaticPath 增加骑乘脚底映射，水面落点按坐骑结算；普通坐骑进入水面后下沉到水格，不获得水上行走。完全入水后可三维移动；水陆混合路线按 carrier 浸水检查实际支撑和落地累计。

所有水域碰撞使用骑手/坐骑联合体积，规划和同步/动画执行一致；动态新增只挡骑手头部的方块也能中止旧路线。重力稳定不把已经浸水的坐骑继续压到底。运动模式、路线费用和退出锁沿用现有规则，不增加坐骑行动队列成员。

测试覆盖骑马从岸上点水面落入水格、动画执行、向下/向上游泳、返回一格岸台、曼哈顿费用、AV 不变、坐骑与骑手按各自眼睛呼吸，以及旧路线新增头顶阻挡/禁止游入空气。首轮测试错误假设骑手脚底必然完全干燥，已改为直接校验 carrier 脚底坐标，呼吸独立性另行断言。
