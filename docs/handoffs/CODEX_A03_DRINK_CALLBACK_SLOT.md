# Codex A03 第一批：饮用回调与容器槽位

2026-10-11。

## 问题与修复

VanillaCombatItems.drink 先临时选中使用槽位，再调用原版 finishUsingItem，最后根据此时的 inventory.selected 写回返回物品。原版回调中的其他模组可改变 selected，导致空桶/空瓶被写到无关槽位，覆盖那里的物品。

现于 finishUsingItem 前记录使用槽位，并向该槽位写回返回堆叠。withSelected 原有 finally 仍负责恢复操作前的选中槽位和同步装备。此修复同样适用于复用 drink 适配器的 native_food。

没有自行回滚原版效果或返还行动费用。以牛奶为例，取消 MobEffectEvent.Remove 只取消对应状态的移除；原版仍消费牛奶、返回空桶，战斗动作也已支付。这与取消整个使用动作不同。

## 回归与范围

真实牛奶饮用测试注册仅匹配测试玩家的原版效果移除监听器，将 selected 改为存有 3 枚钻石的槽位。分别运行允许移除与取消移除两种情况，核对回调次数、钻石保留、原使用槽位仅得到一个桶、原牛奶被消耗、选择恢复、效果是否保留、主要行动已用和 AV 不变。监听器在 finally 注销。

本批只处理回调改变选中索引，不承诺对任意第三方直接替换/移动库存、重入使用、异常或退出的全部事务自动回滚。后续 A03 需分别审计，不能用此修复宣称所有物品事件兼容完成。
