# Codex A10 第三批：空间搜索路径历史

2026-10-10。本批只优化 SpatialRoutes 的历史存储，不修改地面搜索或客户端预览协议。

## 实现

- 原先每次空间边尝试都会复制父节点的完整采样列表，成功节点保留一份完整历史。现节点仅保存自己的不可变新增路段和父节点引用，找到终点后才重建完整输出。
- 每条候选边仍创建新的控制谓词，并从根节点到当前节点按原始顺序回放全部历史，然后检查新增采样。不缓存有状态的周身控制结果。
- 保持队列排序、最优费用表、邻居顺序、采样间距、模式碰撞规则、费用和 512/2048 次取出上限不变。pursue 继续基于最终完整路线裁剪预算前缀。
- 添加 storedSamples 和 avoidedPrefixCopies 统计：前者为入队新增路段的累计样本数，后者为这些入队节点不再复制的前缀引用数量；不包含失败边临时数据、最终结果、对象头和父节点引用，不能当作实际堆内存字节或峰值。

## 回归

新增绕墙空间路线测试，其每次控制谓词都从实体起点记录前一个点，要求历史连续。若省略父链、逆序回放或漏拼前缀，测试将拒绝路线或检测到不连续。另检查每个最终段的真实碰撞、完整三维曼哈顿费用、终点、预览不移动实体，以及分支历史的共享统计。

完整运行日志：`build/spatial-parent-history.log`。验证结果以日志实际汇总为准。协议 22 不变；未提交或推送。

后续仍有地面路径历史复制、多玩家预览负载、水陆切换，不能把本批视作 A10 全部完成。
