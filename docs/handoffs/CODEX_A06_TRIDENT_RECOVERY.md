# A06 三叉戟战内主动回收

2026-10-11。

新增 mineturn:recover_trident 动作、同名 grant 和 mineturn:nearby_thrown_trident 条件。沿用现有动态条件行动栏和 grant 请求，无协议变更、无新客户端代码。默认 range=2.5、主要行动 1、次要行动 0，数据包可覆盖；执行器范围限制为 (0,8]。

本场投掷创建的真实 ItemEntity 登记在 battle.recoverableTridents，归属投掷玩家，范围和方块视线通过才显示条件动作。满背包时可显示禁用原因，不消耗行动。回收要求主背包有一个空位，优先原投掷槽位；一次转移一把，原对象连同耐久/组件转入库存，清空/移除来源实体，并删掉同实体的忠诚返回任务。

实际回收再次检查实体仍加载、存活、同世界、物品仍为单把三叉戟和原登记归属。未登记的普通掉落物、他人武器、销毁或过远的实体不能被此动作回收。退出清理登记；无忠诚实物仍留世界。登记为本场内存态，不跨重启恢复。

三项回归覆盖忠诚/无忠诚原物品唯一转移、原槽位/空背包槽、满包/墙体/过远/销毁拒绝、其他所有者/未登记/退出，以及已手动回收不再忠诚返还。370 项必需 GameTest 全部通过、构建成功：build/trident-manual-recovery-verified.log。首轮 build/trident-manual-recovery.log 的必填 amount 缺失已修正。

客户端按钮出现/消失、返程模型和实际多人网络操作仍待人工验收。未提交或发布。
