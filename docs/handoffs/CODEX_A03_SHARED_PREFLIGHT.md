# A03 第九批：统一玩家预检与远程结算校验

2026-10-11。

checkedAction 复用已有扩展行动的状态快照及防重入保护，现覆盖物品 validateUse、地面物品 validateGroundItem，以及地面/扩展远程动作的结算校验。物品预检额外检查使用槽位的原对象身份、数量和组件；被替换、缩减或修改组件时拒绝执行，不自动回滚回调修改。

offers 的外层条件查询也设置防重入保护；查询期间的嵌套 offers 返回空列表，避免条件函数递归生成界面。正常非当前回合仍可显示授予条件，动作可用性继续由 validateGrant 判定。

远程结算先消费 token，再在受保护校验中调用条件/效果回调；校验造成位移或离场时不继续效果，不退款。离场后不补发射击演出或完成回调。

新增三项回归覆盖物品对象/数量/组件修改、远程结算的重入与目标位移/离场、条件查询中的递归施放/递归 offers。367 项必需 GameTest 全部通过，构建成功：build/all-player-preflight.log。
