# A07 第一批：炽足兽岩浆支撑

2026-10-11。

原版 LiquidBlock 对可站立流体使用 STABLE_SHAPE（方块内 0.5 高），要求源流体且上层不是相同流体；Strider.canStandOnFluid 允许岩浆。旧路线虽然能得到原版支撑，但规划/执行的液体拒绝条件会拦截这种半浸入姿态。

TerrainPath 现在基于原版 canStandOnFluid、源方块和顶部条件计算假想位置的液体支撑。规划清空检查、自动落地、实际支撑和地面逐段执行保持一致：仅允许脚底达到该原版支撑面的实体停留/行走，不允许走入更深岩浆或上层岩浆，也不赋予普通生物岩浆行走。

真实骑乘回归覆盖炽足兽从岸边进入岩浆、纯预览、动画移动、原版半格落点、返回岸边、曼哈顿水平费用、不新增行动者和不推进 AV。另验证普通生物拒绝、下潜到支撑下方拒绝、上方加岩浆后拒绝。
