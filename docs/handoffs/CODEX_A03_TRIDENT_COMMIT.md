# A03 第十批：三叉戟原生提交回调

2026-10-11。

投掷三叉戟的复制耐久、附魔读取和 ItemEntity 生成都发生在支付主要行动之前。新增独立物品提交保护，阻止这些回调递归发起玩家行动；生成前后核对原物品对象/数量/组件、参与者、战斗和预算身份。回调替换物品、离场、抛错或篡改生成物品时丢弃临时掉落物，交给既有安全关闭；原武器和主要行动此时尚未消费。

正常取消生成仍只是无消费的操作拒绝，战斗保持继续。耐久/附魔/生成回调异常包装为执行故障，不被误作预检失败。使用 copyWithCount(1) 修复组件允许堆叠时复制整组的问题。

新增五种生成事件场景（重入、替换、离场、取消、异常）与可堆叠三叉戟单把转移回归。372 项必需 GameTest 全部通过，构建成功：build/trident-spawn-boundaries.log。协议不变，第三方自身已经产生的任意外部副作用不自动回滚。
