# A03：末影珍珠落地事件预检（2026-10-11）

末影珍珠的 NeoForge EnderPearl 落地事件进入共用 checkedAction 作用域。事件期间禁止递归使用物品、结束行动、疾跑或移动；事件返回后重检原 ItemStack 身份/组件/数量、成员、位置、行动预算和战斗版本，然后再次检查落点。
