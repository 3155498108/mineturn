# Codex A03 第五批：原版攻击事件中的离场

2026-10-11。

## 修复

VanillaCombatItems.melee 调用 NeoForge 原版攻击事件后，回调可能使攻击者或目标离场。此前适配器仍会继续直接调用目标的 hurt，绕过已过期的战斗上下文。

新增 BattleAccess.canContinue(target) 查询，检查服务器线程、当前已付费执行上下文、战斗未关闭、攻击者仍为原成员、双方存活且在原维度，以及目标仍参与战斗。默认实现返回 false。原版近战适配器在攻击事件之后、伤害计算回调之后和每个横扫目标前重新检查。

公共执行器在一方离场或换维度后停止补发挥手、动作消息、弹射物演出和动作完成回调；动作动画也检查成员归属。目标死亡但仍在成员表中不会仅因死亡而丢失终结攻击动画。

行动费用已支付，不退款；本批不回滚已经发生的原版伤害，也不能中断第三方事件监听器自身正在执行的代码。原版后置附魔、耐久和其他效果内部回调仍需逐步审查。

## 验证

nativeAttackCallbackDepartureStopsDamage 通过实际请求发起铁剑攻击，分别在 AttackEntityEvent 中移除攻击者或目标。保留额外敌人，确认目标离场后其他人仍可继续战斗。检查目标未受伤、剑无耐久消费、行动已扣、AV 不变、离场锁解除、选中槽位和授权恢复、无运动/射击残留及无离场后的挥手/动作演出。
