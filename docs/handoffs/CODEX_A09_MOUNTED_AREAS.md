# A09：低矮区域与药水云（2026-10-12）

周期区域和进入陷阱按单人受控骑乘组合的完整垂直碰撞箱判断接触，仍只向参战骑手执行一次回调。低矮区域不再因为骑手脚底较高而漏判；进入一次消耗一次陷阱次数，静止放置不重复触发。横向半径、敌我、视线及 AV 计时保持原规则。

原版滞留药水云先把已登记坐骑映射为骑手并去重，再由原版执行药水效果和重施加间隔。原版低云查询只发现坐骑时也能作用于骑手，双方同时被查询到时不会双份结算。坐骑仍不单独进入时间轴；其环境接触和呼吸不受此技能目标策略替代。

综合测试覆盖低矮脉冲、进入陷阱次数、重复触发保护、候选归一去重、实际原版缓慢效果只施加骑手，以及关闭战斗后的候选清空。
